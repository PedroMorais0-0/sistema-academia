# Sistema de Gestão de Academia

Projeto desenvolvido para a disciplina de **Engenharia de Software**.

## Objetivo

Desenvolver a documentação e a prototipação de um sistema para gerenciamento de uma academia, utilizando conceitos de **User Stories, GitHub Issues, GitHub Projects e Figma**.

## Usuários do Sistema

O sistema será utilizado pelos seguintes perfis:

* **Aluno** – consulta seus treinos e acompanha sua frequência.
* **Personal** – acompanha alunos e gerencia suas fichas de treino.
* **Administrador** – gerencia os usuários e os acessos ao sistema.
* **Recepcionista** – realiza o cadastro de alunos e registra suas presenças.

## Funcionalidades

O sistema deverá contemplar funcionalidades relacionadas a:

* Cadastro de alunos;
* Consulta de informações dos alunos;
* Criação de fichas de treino;
* Consulta de treinos;
* Registro de presença;
* Consulta de frequência;
* Gerenciamento de usuários;
* Atualização de fichas de treino.

## User Stories

As funcionalidades do sistema serão detalhadas por meio de **User Stories**, organizadas em GitHub Issues.

Atualmente estão previstas 8 User Stories:

* US01 – Cadastro de aluno
* US02 – Consultar ficha do aluno
* US03 – Criar treino
* US04 – Consultar treino
* US05 – Registrar presença
* US06 – Consultar frequência
* US07 – Gerenciar usuários
* US08 – Atualizar ficha de treino

## Ferramentas utilizadas

* **GitHub** – gerenciamento do projeto e das Issues.
* **GitHub Projects** – organização e acompanhamento das tarefas.
* **Figma** – criação do protótipo e das telas do sistema.
